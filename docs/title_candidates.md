# 称号候选词条库（v1.2.1）

为「前缀 + 主体」固定称号结构准备的**候选词条池**：500 个前缀候选 + 500 个主体候选，
均带描述（desc）与属性加成（bonus），风格延续现有词条（热血奇幻 + 玩梗日常混搭）。
**这是候选库，不入库生效**——请人工筛选后把保留的条目直接粘贴进
`config/game/titles.json` 的 `prefixes` / `cores` 数组。

## 使用说明

- 条目格式与 titles.json 完全一致，粘贴即用；`id` 可自行重命名，但**同一池内不可重复**
  （前缀池与主体池互不影响）；`weight` 建议保持 5（越大越常被抽到）。
- `desc`：称号描述片段，卡牌上按「前缀描述，主体描述。」拼接展示，建议 4~6 字。
- `bonus`：属性加成，量纲与属性表一致——`hp`/`atk`/`def`/`spd` 为 ×100 整数量纲
  （参考幅度：hp 200~800、atk 50~250、def 50~250、spd 50~200），
  `crit`/`dodge` 为百分数（1~3）。**一个词条最多三种属性，可大胆用负值**
  （玻璃大炮、重甲减速等双刃剑组合）。
- 设计思路：加成与词条语义对应（胆小→闪避+攻击负、玻璃→攻高血负、坦克→防高血厚）；
  前缀偏「修饰/连接」（可与任意主体组合成句，如「可能是」「禁忌」「打败恶龙的」），
  主体偏「身份/名词」（职业、神话生物、抽象概念、日常玩梗）。
- 本库已确保池内名字不重复，且与 `titles.json` 现有词条不重复。
