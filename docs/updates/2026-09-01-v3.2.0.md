## 变更内容

### 一、变量表与表达式系统（新模块 namefight/expr.py）

**所有数值参数**（chance / value / gain / mult / turns …）除直接数值外，允许写
**表达式**：数字、`$变量`、`+ - * / ( )` 与 `min / max / abs / floor`。变量表：

- 自身 / 敌方：`$self.hp` `$self.hp_pct` `$self.atk` `$self.def` `$self.spd`
  `$self.crit` `$self.dodge` `$self.gauge` `$self.gauge_pct`
  `$self.damage_dealt` `$self.mark:<键>` `$self.stacks:<状态id>`
  `$self.total:<状态id>` `$self.records:<状态id>`（`$enemy.*` 同套）；
- 上下文：`$ctx.dmg`（本次伤害）`$ctx.absorbed`（本次被减免量）
  `$ctx.loop`（循环轮次）`$ctx.tick`（当前刻）；
- 状态效果图里 `$value` 等施加参数同表可用（原 "$参数" 引用并入表达式语法）。

示例：`marker(add, value=$enemy.mark:连击 * 2)` 把对方「连击」标记翻倍叠到
自己身上；`stat_mod(gain=$enemy.atk * 0.2)` 按对方攻击永久加攻。手写递归
下降解析器（无 eval、纯标准库、按文本缓存编译结果）；除零与缺失变量按 0
（标记层数语义）；配置加载时做语法校验（写错早暴露）；求值在共鸣钳制之前。

### 二、共鸣与表达式统一（用户方向）

共鸣运行期本质就是表达式（`基数 × (1 + 率 × 变量式/基准)`）——v3.2.0 起
**派生期直接把共鸣槽生成为表达式字符串写进参数**，运行期与手写表达式走
**同一条求值路径**（battle._proc_params 只剩表达式求值 + 共鸣规格钳制）；
`links` 保留为显示元数据（公式括号 / 尾句 / live 占位符 / link_calc 前端
实时重算协议完全不变）。随机数消耗顺序与个性化流水线不变（确定性契约）。

### 三、标记系统完备（调研：set/clear/toggle/increment/timer/wait 词汇表）

- **marker 原子**五种操作：`set` 置位 / `clear` 清除 / `toggle` 翻转 /
  `add` / `sub` 层数 ±value（减到 0 自动清除）+ 可选 `turns` 存在刻数
  （到期整条消失，每刻结算）；
- **has_marker 条件**增强：可选 `op + count` 层数比较（复用 compare 的
  4 种运算；缺省 = 布尔 ≥1）；`no_marker` = 层数 0；
- **等待类事件钩子 ×2**：`on_status_gain` / `on_status_lose`（自己获得 /
  失去在场状态时触发——施加、到期、驱散、清除都算；事件上下文中
  has_status / no_status 直接比对刚变化的状态）；
- 合并分析：需要展示 / 引擎结算 / 参数化的"标记"继续用状态系统
  （count 叠层 + stacks_cmp + status_ctl 已覆盖）；marker = 图内自足的
  私有计数开关（免预定义、自由键名）。
