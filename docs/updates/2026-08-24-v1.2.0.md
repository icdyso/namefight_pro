# 更新记录 - v1.2.0（实时共鸣数值错位修复 + 公式小值有效数字 + 工坊悬浮提示）

- 日期：2026-08-24
- 类型：fix + feat
- 提交：`97398c4`

## 变更内容

1. **修复对战实时共鸣数值交叉错位（bug）**：
   - 现象：带两个共鸣变数的技能（如「坚守壁垒」）在对战中实时刷新时，
     两个数值会填反——例如显示「自身生命不低于 7.48%（70.00+🌀*4.16）% 时，
     所受伤害降低 90.00%（6.31+【己方+对方】❤️*0.00）%」，门槛与效果值互换。
   - 原因：前端 `fillLiveText` 按占位符**在文本中出现的位置**依次填入
     `link_calc[0]`、`link_calc[1]`；占位符顺序 = 模板参数顺序
     （nat_bulwark 为门槛在前、效果值在后），而 `link_calc` 顺序 = 共鸣
     槽位顺序（bulwark 的 targets 为 value、threshold）——两者不一致时错位。
   - 修复：live 占位符由裸 `\u0001` 改为 `\u0001 + 槽位序号`（序号 = 变数在
     `eff.links` 中的下标，与 `link_calc` 下标一致），前端按**序号**取值替换。
     新增测试锁定该协议：按序号填充必须还原出与卡牌估算文本完全一致的结果。
2. **共鸣公式小值显示（显示层）**：公式内数值由「保留两位小数」改为
   「保留两位有效数字」——低于 0.1 的值不再被吞成 `0.00`：
   - 百分字段括号内的纯数字转百分数形式：`（6.31 + 【己方+对方】❤️*0.0021%）%`；
   - 数值字段的百分数系数加深小数位：`*0.0042%`（原先 `*0.00%`）。
   新增助手 `_format_formula_number` 与对应单元测试。
3. **创意工坊悬浮提示（功能新增）**：工坊每个选项（字段标签、表头、分区标题、
   技能卡各栏、触发时机下拉等）附带「?」悬浮提示，中文说明该量的含义与
   相关量的关系（如免伤率公式、行动槽阈值与速度的关系、共鸣归一化方式等），
   对项目有基础了解即可上手。提示文本按工坊既有约定书写于 `workshop.js`
   （TIPS / SECTION_TIPS），样式见 `workshop.css` 的 `.ws-tip`。

## 动机

- 用户发现壁垒类双变数技能在对战中两个共鸣数值填反，且公式合并系数过小
  时显示为 `*0.00` 失去信息量；工坊选项缺乏说明，上手成本高。

## 对确定性的影响

- **无**。对战引擎（battle.py）与派生逻辑（fighter.py 的随机消耗）均未改动；
  变更只涉及展示层（公式数值格式化、live 占位符协议）与工坊页面。
  同名斗士的属性/技能/称号/对战结果完全不变。
- `live_text` / `live_text_simple` 的占位符格式变化（`\u0001` -> `\u0001<序号>`），
  属 API 展示字段的内部协议，前后端同版本配套更新。
