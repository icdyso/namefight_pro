# 更新记录 - v1.1.0（三角形分布 + 真实伤害视作攻击 + 中毒每刻结算 + 公式显示改版）

- 日期：2026-08-23
- 类型：feat!（breaking，会改变所有同名结果）
- 提交：`dfc1877`

## 变更内容

### 1. 数值随机改为三角形分布（用户指令）

全部数值类随机（属性投掷、技能数量、熟练度、个性化扰动倍率、共鸣倍率、
伤害浮动）由 `next_gaussian`（Box-Muller 高斯 + 端点截断）改为
`next_triangular`（**两个均匀随机数取均值**，每次消耗两个均匀数，随机消耗
次数不变）。三角形分布密度在区间中点最高、向两端线性递减，**天然落在
区间内，端点不再发生截断堆积**。
（旧版高斯 σ = 宽/4 截断，使约 4.8% 的数值被硬压到边界 0/100——正是此前
「色鬼色」出现大量极限值、双技能熟练度同为 0 的根因；已用 20 万样本统计
验证旧逻辑「按设计正确」，本次按用户要求从根上消除边界堆积。）

### 2. 不屈意志衰减改为 ×0.5 乘算

`iron_will` 的 `decay` 由 0.3 改为 0.5。引擎本就乘算
（`will_chance *= will_decay`），本次仅改配置数值；触发序列 50% -> 25% ->
12.5% -> 6.25% …已专项验证。平衡补偿：概率 44% -> 52%、回复 20% -> 28%。

### 3. 中毒改为每刻结算

毒伤从「拥有者行动时机结算」改为「**每刻开始结算**」（`battle.py` 主循环
每刻开始段），眩晕/打断不再影响毒；淬毒之刃由 380/动 改为 38/刻 × 12 刻
（总量相当，但不再依赖目标是否行动）。文案同步（`nat_poison`、`buffs.poison`、
`battle.json`）。

### 4. 真实伤害（雷罚）视作一次攻击

雷罚每道落雷从「直接 `_hurt`、不触发防守」改为「**走 `_defend` 防守结算**」：
无视防御与闪避、不可暴击，但锻痕/壁垒/反甲等**伤害减免可生效**（含壁垒
免疫掷骰、反甲反弹），并照常触发受击反应（乘胜叠层/怨念积攒/以牙还牙记录）。
被反甲反弹致死时雷罚链终止。

### 5. 大器晚成附带加攻

`tempo` 效果新增 `atk` 字段（10）：触发时速度 +1 且攻击 +10（无上限叠加）。
`battle.py` tempo 段同步累计 `tempo_atk_total`，战报 `tempo_stack` 与
`buffs.tempo` 增加攻击展示；`fighter.py` 补 `nat_tempo` 参数、`RESONANCE_SPECS`
与 `_FIELD_UNITS` 表项。

### 6. 熟练度显示为真实投掷值（无需改动，验证通过）

`fighter_to_api` 的 `mastery` 与 `mastery_text` 一直输出真实投掷值
（如「熟练度 30：触发率 9.74%」）；改为三角形分布后不再出现边界堆积。

### 7. 共鸣公式显示改版

百分数字段公式括号内改为**纯数字（两位小数）、无内层百分号**，百分号移到
括号外：`伤害提升至 375.52%（355.61+❤️*0.01）%`（`fighter.py`
`_link_formula`）。绝对数值字段（毒伤/破甲/行动槽等）基数仍为整数、系数仍为
百分数（其系数过小，纯两位小数会失真）。前端实时计算（`live_text`/
`link_calc`）口径不变，无需改前端。

### 8. 用户手动调参（全部保留，未覆盖）

- `attributes.json`：命 [10000,30000]、速度 [5,15]、暴击基准 15/[5,30]；
- `battle.json`：闪避上限 60 -> 80、种子分隔符 `\u001f` -> `-`；
- `system.json`：大小写敏感 `case_sensitive: true`；
- `skills.json`：技能数下限 2 -> 1、`md5_variance`/`mod_variance` 区间 [0.5,1.5]、
  新增前缀「极限」、后缀「蹈隙」改名「突袭」、若干技能文案与描述改写。

### 9. 平衡重调（七轮蒙特卡洛）

三角形分布 + 用户调参使对局样本整体洗牌。六千场蒙特卡洛下各技能持有者胜率
收敛至 **45.5%–56.1%**（平均对局 ~129 刻，位置偏差 1.87%）。主要调整：
壁垒（减伤 25%->8%、免疫 9%->3%、门槛 60%->70%）、重击（×3.0->×2.2、暴击
+40->+25、概率 16%->14%）、净化（概率 26%->13%、回复 320/260->190/215）、
大器晚成（概率 27%->16%、新增 +10 攻）、眩晕重锤（17%->12.5%、6->4 刻）、
以牙还牙（×0.6->×0.38）、荆棘（31%->23%）；上调不屈（44%/20% -> 52%/28%）、
洞悉（暴击 +5->+6）、孤注一掷（×2.1->×2.2）。

## 动机

- 三角形分布消除高斯截断的边界堆积，消除用户观察到的极端值问题；
- 真实伤害吃伤害减免更符合「可被减免」的直觉；中毒每刻结算不依赖行动节奏、
  语义与「持续 N 刻」一致；不屈 ×0.5 乘算使衰减曲线更明确；
- 公式显示去内层百分号更简洁。

## 对确定性的影响

**Breaking**：分布算法（高斯 -> 三角形）改变所有同名派生结果与对战结果；
中毒结算时机、雷罚防守路由、大器晚成加攻、不屈衰减、若干技能数值均会改变
结果。用户手动配置（属性区间/闪避上限/分隔符/大小写/技能区间）本就属「输入
变化」，同样改变同名结果。核心不变量（同名同命、顺序无关、确定性种子）不受
影响，由测试守护。
