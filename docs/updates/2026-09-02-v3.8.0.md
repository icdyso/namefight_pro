# v3.8.0 共鸣禁用选项 + 新原子 hp_swap + 新技能「命运天平」

日期：2026-09-02 ｜ 版本：3.8.0 ｜ 性质：**breaking（技能池 27 个，同名斗士
抽取结果改变；触发率契约放宽）**

## 1. 共鸣禁用选项

用户反馈：有些属性不想让它共鸣时需要明确的「不共鸣」设置（随机仍可能抽中）。

- 覆盖表 `variable` 留空 = **禁用**：该参数永不共鸣（不掷概率、不占槽位）；
- 编辑器共鸣绑定下拉新增「**不共鸣（禁用）**」（随机 / 禁用 / 六属性三态），
  禁用时不显示模式与倍率；
- 派生层实证：禁用后技能文本无公式括号、link 为空。

## 2. 新原子 hp_swap（交换双方当前生命）

「交换生命」无法由 hp_mod 组合精确表达（两步治疗/流失存在中间态，
$self.hp 在第一步后已变），按最小原子哲学新增独立原语：

- hp_swap：以旧值一次性互换双方当前生命，各自钳制不超过自身上限
  （不低于 0）；不触发受击反应与不屈；挂任意钩子（ALL_HOOKS）；
- hp_mod 同步开放 on_hit_taken 挂点（受击后自扣类效果）。

## 3. 新永久技能：命运天平 fate_scale

被攻击结算后（on_hit_taken）判定：

- **对方生命比例高于我方**：9.5% 概率交换双方当前生命值
  （各自不超过上限）——绝境翻盘；
- **否则**：60% 概率自扣 350 点（保底 1 点，不至自灭）——优势期代价；
- 熟练度缩放双触发率（×0.6–1.5）；权重 7；
- 自然语言描述：`被命中时，敌方生命比例 > 自身生命比例，有 9.50% 概率，
  与对方交换当前生命值（各自不超过上限），否则有 60.00% 概率，
  消耗自身 350 生命。`
- 战报：fate_swap（⚖️ 天平倾斜：交换生命，双方新值）/ fate_cost（💔 代价）。

## 4. 触发率契约放宽（测试更新）

v0.9.1 契约「同一技能的多个 chance 必须相同」不再适用（命运天平的
交换 / 自扣本就是两种不同概率）；改为：同一技能至多两种 chance，
跨技能仍互不相同。
