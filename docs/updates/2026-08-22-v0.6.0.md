## 变更内容

1. **共鸣 v3：修正技能自身数值，不再附加伤害（需求 1）**：
   - 共鸣不再给没有伤害成分的技能强行加附伤，而是**按比例修正技能自身的某个参数**；
     目标字段由 `variable_link.targets` 按效果类型显式配置（**JSON 中的字段标识**）：
     眩晕重锤 → chance（触发率）、重击/斩杀 → value（倍率）、淬毒之刃 → damage（毒伤）、
     连击 → chance；
   - **基础值归一化**消除量纲差异：`coeff = rate × (变量当前值 ÷ 变量基础值)`（比例）
     或 `rate × ((己方变量 − 敌方参照) ÷ 基础值)`（差值，可为负）；
     所有变量倍率区间统一为 0.25–0.65，典型修正 +25%–65%；
     截断：chance ∈ [2%,95%]、value ∈ [0.05,5.0]、damage ≥ 0、turns ≥ 1；
   - **描述填充最终百分比**：主句数值即共鸣修正后的最终值（敌方按基础值估算），
     共鸣句式给出归一化公式与当前值，措辞按要求修正：
     「攻击时有 13% 概率眩晕敌方……敌方生命越高，触发率越高（触发率 ×
     （1 + 敌方生命 ÷ 100 × 30%），当前约 13%）。」
     差值模式措辞改为「己方速度**高于**敌方速度**越多**」；
   - 战报改为「⚡ 以敌方生命共鸣（比例），触发率变为 13%！」。
2. **词缀数值个性化（需求 1）**：词缀修正值按名字高斯缩放
   （`name_modifiers.mod_variance` = [0.7, 1.3]），tooltip 显示缩放后的实际值；
   个性化消耗顺序更新为：chance → value → damage → 前缀(是否→抽取→缩放)
   → 后缀(是否→抽取→缩放) → 共鸣。
3. **回放降速至 1/3（需求 2）**：逐刻回放基础时长 85ms → **255ms/刻**。
4. **极速对战接口（需求 3）**：`POST /api/battle/fast`
   - 引擎新增 `run_battle(..., snapshots=False)`（不为战报生成状态快照，
     胜负/事件序列与完整模式完全一致，有测试守护）；
   - 接口不做任何文案渲染，支持 `{"a","b","runs"}` 单对重复与
     `{"pairs":[[a,b],...],"runs"}` 批量；返回紧凑结果与耗时（ms）；
   - 实测约 **0.25ms/场**（1000 场 ≈ 250ms），批量 3 对 ×100 次 ≈ 65ms；
     与普通接口结果逐一比对一致。
5. 文档同步：GAME_SPEC.md（共鸣 v3 公式/描述格式/变量表/回放速度/fast 接口/
   skills.json 指南）、AGENTS.md（API 表、个性化顺序）、README。
