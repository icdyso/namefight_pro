## 变更内容

### 一、条件抽象：比较值与值（用户方向）

4 个生命阈值条件（self/target_hp_below/above）合并为通用 **`compare`** 条件：
`left op right`——左右值各取 14 种值源之一（自身/敌方 × 生命比例、攻、防、
速、暴击、闪避、行动槽比例），右值还可取 `const` 固定值；运算 4 种
（< / ≤ / > / ≥）。「自身生命 < 30%」「敌方速度 > 自身速度」「自身暴击 ≥ 敌方
闪避 ×2」……全部一个节点表达。

### 二、新组件（合计：条件 9 种、原子 13 个、结构 1 种、状态修饰 10 种）

- **条件 +2**：`compare`（上述）、`stacks_cmp`（己方/敌方某状态层数与值比较）；
  另恢复 `has_marker` / `no_marker`（配合 marker 原子）；
- **原子 +2**：`marker`（标记设置/清除——图内自由布尔状态，可搭一次性、
  开关、锁定类逻辑）、`status_ctl`（状态操控：延长/缩短在场刻数、增减层数、
  强制清除，无视可驱散标记）；
- **原子增强**：`strike` 新增 `lifesteal`（本次攻击按伤害比例吸血）；
  `hp_mod` 新增 `curhp` 基准（当前生命比例）；`loop` 新增 `mode=count`
  （固定次数，不掷骰；原衰减续链为 mode=chain）；
- **状态修饰 +1**：`shield` 护盾池——受到的伤害先按施加顺序消耗护盾余量
  （余量存于状态参数、实时显示），配套示例状态 `barrier`（护盾 500/3 刻，
  可驱散）与战报模板 shield_absorb / barrier_gain；
- 外部调研说明：连线交互按主流节点编辑器（Node-RED / Blender / Rete）惯例
  实现——边加宽命中点击选中 + Delete 删除、**右键直接删除**、**拖到目标
  节点主体即可连接**（不再要求精确落在端口圆点上，loop 容器头部同理）。

### 三、编辑器修复（用户反馈）

- **连线无法删除**：每条边增加 14px 透明命中层 + 右键直接删除；
- **循环外连线**：落点解析改为「端口优先、节点主体次之」，从容器外拖到
  容器头部即连接 loop 节点，从 loop 出端口拖到任意节点即出循环；
- 雷罚等全部图重排，循环体下移避让容器头部说明区（v3.0.0 收尾时已含）。

## 对确定性的影响

- **breaking**：execution / bulwark / last_stand 的阈值条件改写为 compare
  节点（判定语义等价：≤/≥/< 口径对齐原 below/above 含义），但 compare 的
  参数名与节点形态变化使随机数消耗路径不变、图结构变化——同名结果仍可能
  因描述与共鸣候选顺序微变而不同；护盾若被技能引用将改变对局（当前仅为
  可用组件，未挂任何技能）。
