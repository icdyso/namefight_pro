# 更新记录 - v0.10.0（配置单文件化 + 防御倒数免伤 + 量纲×100 全整数 + 战报富文本）

- 日期：2026-08-23
- 类型：feat（**breaking**：配置结构重构 + 数值/规则/量纲变更，同名对战结果与 v0.9.1 不同）
- 提交：`a5b6c07`

## 变更内容

### 1. 配置单文件化：文案与数值合并，删除英文支持

- `config/locales/` 目录**整体删除**（含 zh 与 en 各八个文件）；多语言体系移除，
  游戏固定为单语言 `zh`；
- 数值与文案合并保存在 `config/game/*.json`（六个文件）——每个条目的**文字与其
  数值/加成绑定在同一条目内**：
  - `attributes.json`：属性区间 + 显示名 + emoji；
  - `skills.json`：技能效果参数 + 名称/风味描述 + `stats` 模板 + 词缀（名称与修正值同条目）；
  - `titles.json`：称号结构 + 字段池（名称/描述/**bonus 加成**同条目）；
  - `battle.json`：战斗常数 + `battle_log` 战报模板 + `buffs` 文案 + `playback` 回放配置；
  - `ui.json`（新增）：界面文案；`system.json`：版本 + 归一化规则（移除语言列表）；
- `config.py` 删除 `Locale`/`load_locale`，全部文案挂载于 `GameCfg`
  （`stats`/`battle_log`/`buffs`/`ui` + `ref_name`）；`text.py`/`fighter.py`/`battle.py`/
  `server.py` 的 locale 参数全部改为 `game`；
- API：`/api/text` 返回 `{lang, version, ui, playback}`（lang 参数仍被接受但忽略）；
  `unknown_locale` 错误码移除；前端移除语言切换器。

### 2. 数值与规则（breaking）

- **生命翻倍 + 量纲×100**：非百分比基础数值整体 ×100——HP `[16000, 24000]`
  （基准 20000，即旧 100→200 再 ×100）、攻/防/速 `[1000, 2000]`（基准 1500，
  即「10–20」×100）；crit/dodge 百分数区间不变（5–20 / 5–15）；
  称号加成、技能绝对值参数（毒伤 380、回春 550/150、破甲 460、叠速 97、
  行动槽推进 3300/5600、斩断倒退 900）、`gauge_threshold`（10000）、
  `min_damage`（100）同步 ×100；`defense_constant` = 2500；
- **防御改倒数百分比免伤**：`免伤率 = DEF / (DEF + defense_constant)`
  （可配置常数 K=2500），伤害公式由「攻击 − 防御」的直接扣减改为
  `dmg = raw × (1 − 免伤率)`；破甲降低 DEF、穿透按比例抵消灭伤率
  （洞悉 pen=1 时无视全部防御）；
- **全部计算结果取整**：多步浮点计算只在**最终应用时取整一次**
  （`battle._r`）；属性投掷（非百分比）、伤害/治疗/吸血/毒/流血/回春/破甲/
  叠速/血契转化/行动槽推进等均以整数落地；血量全程保持整数；
  百分数内容（触发率/比率/倍率）不变，仍保留 2 位小数显示；
- **显示回退真实值**：删除 `display_ref` 白板 100 换算体系
  （`display_factor`/`display_units`/`_FIELD_UNITS` 换算用途），
  卡牌 / HUD / 快照 / 战报数值 / 共鸣公式基数与系数**一律直显引擎真实值**。

### 3. 战报富文本与前端显示重做

- 后端为每条战报输出 `rich` 富文本段列表（`{t, k}`：plain / name-a / name-b /
  skill / dmg / heal），各段拼接与原 `text` 完全一致（有测试保障）；
- 技能使用行改为「**XXX 使用了 XXXX**」，其后自动附一行该技能实例的
  **个性化描述**（简易模式同步生效）；
- 前端战报：阵营名**红/蓝加粗**（a=红方、b=蓝方）、技能名**各自配色加粗**
  （按技能 id 确定性散列出 hue，卡牌与战报同色）、**伤害红色 / 治疗绿色**
  （不加粗）；
- **每条消息停顿**：回放改为逐条推进，停顿时长可配置
  （`battle.json` 的 `playback.message_delay_ms`，默认 320ms，÷ 倍速）；
  跨刻时行动槽按每刻推进量补进动画；
- **属性条重新量化**：投掷区间线性映射到 **8%–92%**——永不空条、永不全满；
- **战斗实时属性显示**：HUD 扩展为六维（⚔️🛡️👟🎯🌀 全部真实引擎值），
  随每条战报快照刷新、数值变化时金色高亮闪动；**行动条显示数值**
  （如 `440/10000`，快照新增 `gauge_pct`/`gauge_pct_gain`/`gauge_threshold`）；
- **血契标记修复**：只显示**累计转化的攻击量**（「累计攻击 +238」），
  不再显示静态技能参数；类似标记（渐入佳境等）均展示累计/动态值。

### 4. 平衡性重调（防御改制 + 生命翻倍后的新环境）

四轮固定种子蒙特卡洛（10000 场）调参，最终全部 25 技能持有者胜率
**46.5%–54.6%**（目标 45%–55%）；平局 0.16%、平均 100.6 刻、位置偏差 1.72%。

主要调整：削弱续航/DoT（净化 73.1%→51.8%、淬毒之刃 68.7%→54.3%、
千锤百炼 61.0%→51.5%、回春术 61.0%→52.9%、撕裂、不屈意志），
加强自伤/蓄力型（燃血轰击 27.9%→53.2%、血契 38.7%→52.0%、重击 40.0%→49.9%，
大器晚成改为 28% 概率 +97 速度）。

## 动机

- 称号的文字（locale）与属性加成（game）分居两文件，维护时容易漏改一半；
  英文支持并无实际使用者，多语言拆分的成本大于收益——按用户要求合并为
  单文件、删除英文；
- 防御直接扣减在属性随机后强度失真（高防近似免疫低攻），改为倒数百分比
  免伤可获得平滑且可配置的减伤曲线；生命翻倍拉长对局，让技能循环更充分；
- 量纲 ×100 + 结果取整让数值观感更「整数化」（经典 RPG 风格），同时保证
  多步计算的舍入误差不累积（只在最终应用时取整一次）；
- 战报纯文本无法表达阵营/技能/伤害的视觉区分；血契标记显示静态参数
  而非累计值属于显示缺陷。

## 对确定性的影响

- **Breaking**：
  - 量纲/区间/防御公式/技能参数改变 → **同名斗士属性与同名对战结果全部改变**；
  - 配置结构重构（locales 删除、game 文件合并）→ 配置快照不同，派生结果
    视为 v0.10.0 新基线；
  - 取整策略引入引擎（应用时取整）→ 伤害/治疗数值为整数，随机数消耗
    顺序不变（属性投掷仍为每维一次高斯，消耗顺序未动）；
- 不变性保持：同名同命 / 输入顺序无关 / 跨进程一致 / 镜像对战全部由
  测试守护（`test_determinism.py` 全绿）。
