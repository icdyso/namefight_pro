# v3.6.0 参数联动显隐（show_if）+ 表单全中文化 + 攻击链细分

日期：2026-09-02 ｜ 版本：3.6.0 ｜ 性质：功能（对战结果不变；技能描述文本
中雷罚引导语改为「替代攻击时」）

## 1. 参数联动显隐（show_if）

用户反馈：选「固定量」基准时不应再出现「比例」字段；能填什么应随下拉联动。

- `ParamSpec` 新增 `show_if = (依赖键, 允许值元组)`：仅当依赖参数取这些值时
  该参数适用（依赖键缺省取其枚举首项，如 basis 缺省 flat、type 缺省 heal）；
- 规则覆盖：hp_mod（固定量↔value / 比例基准↔ratio；流失才有 can_kill 与
  floor1）、compare（右值=常数才有 value）、has_marker（选了比较运算才有
  count）、strike（有基准才有 value）、marker（叠/减层才有 value）、
  status_ctl（清除不需要 value）、loop（chain 才有续链概率 decay）；
- 三处共用同一判定（`effects.spec_applicable` / schema 下发 / 编辑器
  `visibleSpecs`）：节点表单联动显隐、新建节点默认值只填适用参数、
  共鸣绑定候选只列适用参数、**派生层共鸣候选同规则过滤**（现网技能本就
  只带适用参数，结果不变）。

## 2. 表单继续汉化 + 语义说明

- 参数键中文名（stats `fld_*` 词表，约 35 词）：「可致死 can_kill」
  「保底 1 点生命 floor1」「数值基准 basis」等——显示为中文名 + 原键
  （便于对照 JSON / 表达式引用，不破坏表达式结构）；
- 比例基准语义改写：按目标最大生命的比例 / 按目标当前生命的比例 /
  按施加者攻击的比例 / 按本次造成伤害的比例；
- ratio 提示注明口径：「与所选基准相乘的比例系数，0.06 = 6%」。

## 3. 攻击链细分（附带 vs 替代）

「攻击时」一个词同时覆盖附带效果与替代攻击，读者无法区分。v3.6.0 起
自然语言描述按子树内容区分：on_attack 子树含 `mode=replace` 的 strike
（雷罚——本次攻击被替换）时引导语用「**替代攻击时**」，否则仍「攻击时」
（修饰 / 施加类，攻击照常）；调色板悬浮说明同步改写。
