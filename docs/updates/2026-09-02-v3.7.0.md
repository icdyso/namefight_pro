# v3.7.0 完全在线做技能：全局设定面板 + 触发率可共鸣 + 共鸣对新技能即时可用

日期：2026-09-02 ｜ 版本：3.7.0 ｜ 性质：**breaking（chance 进入共鸣候选池
改变派生随机流，同名对战结果改变）**

## 1. 技能全局设定面板（编辑器技能列表顶部「⚙ 技能全局设定」）

skills.json 顶层旋钮全部可视化，做新技能不再需要 JSON 源码模式：

- **技能抽取**：skill_count 上下限；
- **数值扰动**：md5_variance 区间；
- **变量共鸣**：chance / max_slots / 四种模式权重 + 变量池表格
  （变量改名、权重、倍率区间、差/和参照属性下拉、增删行）；
- **名称词缀**：前后缀概率、缩放区间、前后缀池（JSON 区编辑）。

## 2. 触发率可共鸣（恢复 v1「触发门槛」共鸣）

- chance 条件参数 `link=True`（钳制 [0.02, 0.95]），触发率可随属性浮动；
  描述显示「有 79.03%（52.50 + 👟*2.36%）% 概率」式公式与
  「己方速度越高，触发率越高」尾句；
- **breaking**：chance 进入共鸣槽候选池改变派生随机流，全部技能的
  个性化数值与共鸣抽取结果改变（现网配置无 chance 共鸣覆盖，改动源于
  随机流位移）；
- 顺带修复：共鸣注入路径的 compare 固定值残留「常数」前缀（与 v3.3.1
  静态路径不一致）；live 公式括号计数测试改为只数公式括号。

## 3. 共鸣绑定对新技能即时可用

- 共鸣绑定行改为列出**全部**可共鸣参数（未填数值的也列出，标注
  「未设值，绑定时自动填默认」），绑定动作自动写入安全默认值——
  新建技能添加节点后立即可配共鸣，无需先手填参数。
