- 提交：`<见 git log>`

## 变更内容

1. **共鸣与技能描述标准化（需求 1）**：
   - 共鸣描述统一为「XX越XX，附加伤害越高」句式并**内联计算公式（带单位）**：
     比例模式「{stat}越高，附加伤害越高（+ {stat} × {pct} 点）。」
     差值模式「{own}越高于{enemy}，附加伤害越高（+（{own} − {enemy}）× {pct} 点）。」
     实例：「己方生命越高于敌方生命，附加伤害越高（+（己方生命 − 敌方生命）× 7% 点）。」；
   - **全部技能描述改为标准化自然语言**：由 locale `stats.json` 的 `nat_<效果类型>`
     模板 + 个性化真实数值生成，单位随文（点 / % / 次行动），如
     「攻击时有 36% 概率使敌方中毒：其每次行动损失 2 点生命，持续 3 次行动。」；
     卡牌主行显示自然描述、副行保留风味短句；原 stats 参数行与 detail 字段移除。
2. **移除属性随机与稀有度（需求 2）**：
   - 属性改为**固定基础值**（HP 100 / ATK 13 / DEF 5 / SPD 10 / CRIT 12% /
     DODGE 10%），`attributes.json` 改为 `base` + 展示用 `min/max`；
     斗士差异完全来自称号加成、技能组合与个性化；
   - **稀有度系统整体删除**（配置、派生、API、卡牌徽章、locale 文件与文案、
     测试与文档全链路），不再有随机属性倍率。
3. **数值类随机全部改为高斯分布（需求 2）**：
   - `DetRng` 新增 `next_gaussian`（Box-Muller，每次消耗两个均匀数，确定性不变）
     与 `next_gaussian_range`（离散）；
   - 适用：技能数量、个性化扰动倍率（chance/value/damage）、共鸣倍率、
     战斗伤害浮动；离散选择（选哪个技能/称号/变量等）仍为加权均匀。
     分布参数：均值 = 区间中点，σ = 区间宽 ÷ 4，越界截断。
4. 文档同步：`docs/GAME_SPEC.md` 全面更新（v0.5.0：新随机体系、自然语言模板、
  属性表、JSON 指南改为 6 个 game 文件 + 9 个 locale 文件）；AGENTS.md 与
  README 同步。
