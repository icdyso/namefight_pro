## 变更内容

### 一、效果原语最小原子化（23 个原语 → 11 个原子 + 1 个结构）

技能逻辑完全拆分为明确规则集中的**最小原子**，一切技能行为 = 原子在图上的组合：

| 类别 | 原子 | 说明 |
| --- | --- | --- |
| 攻击方式 | `strike` | 一次攻击：目标 / 倍率 / 真伤 / 穿透 / 暴击加成 / 必中 / 追加·替换·附加三模式 / 基准（记仇总和 / 被减免量） |
| | `hit_mod` | 修饰本次攻击（倍率 / 穿透 / 暴击 / 必中） |
| | `taken_mod` | 减免本次所受伤害（被减免量供反弹） |
| | `grant_immune` | 完全免疫本次伤害 |
| 基础变动 | `stat_mod` | 属性永久 ±（可按吸血记录折算——血契转化） |
| | `hp_mod` | 体力变动：治疗 / 流失（可致死或保底 1 点）；固定量 / 最大生命比例 / 施加者攻击比例 / 本次伤害比例 |
| | `gauge_mod` | 行动槽推进 / 倒退 |
| 施加与驱散 | `apply_status` | 施加状态（唯一状态入口；参数覆盖定义默认值） |
| | `cleanse` | 驱散（双方 / 自身 / 敌方，按种数回复） |
| 记录与信号 | `record` | 记录所受伤害（记仇）/ 吸血量 |
| | `skip_action` | 吞掉本次行动（眩晕 / 蓄力占用） |
| 结构（循环） | `loop` | 子树反复执行：第 1 轮必定执行，第 i 轮按 decay^(i-1) 续链，至多 max 轮 |

用户示例的对照实现：
- **雷罚** = `on_attack → chance(78%) → loop{max 9, decay 0.93} → strike(真伤 0.27，替换攻击)`；
- **燃血自耗** = `hp_mod(自耗 5% 最大生命，保底 1 点) → hit_mod(×2.15)`——「给自己挂每刻流失标记」
  的模式同样可表达（见毒 / 流血状态定义），本次迁移保持即时支付语义；
- **永久成长** = `apply_status(tempo)`，tempo 状态 mods 声明「每层 速度+100、攻击+10」纯数据生效。

### 二、图语言补全：判断 / 分支 / 循环

- **条件节点出边分两条**：上方 pass 圆点（通过）/ 下方红色 fail 圆点（失败分支）——
  孤注一掷 = `chance(39%) → chance(39%) [×2.2 / 否则 ×0.5]`；疾影 =
  `chance(62%) → 本次暴击？[前进 4800 / 否则 2800]`；
- 新条件：`last_crit`（本次命中为暴击）、`has_status` / `no_status`（原标记条件并入状态）；
- `once_per_battle` 修复：仅当下游子树真的执行了原子才消耗一次性标记（背水一战
  时机未到不占次数——v2 首次求值即占位导致永不触发）。

### 三、状态定义 v3：数据 + 自带效果图（可分状态编辑）

`battle.json` 的每个状态自带：策略字段（`stack` 叠层方式 / `expire` 到期方式 /
`interval` tick 间隔 / `reset_on_miss` 落空清零 / `lethal` 致命拦截——不屈）+
`params` 数值参数（施加可覆盖、可个性化可共鸣）+ `mods` 被动修饰表（8 种 kind：
增伤 / 减伤 / 攻防速乘区与加值 / 破甲 / 吸血）+ **`effects` 效果图**（与技能图同格式，
钩子为 5 个状态钩子：施加时 / 每 interval 刻 / 拥有者行动时 / 替换拥有者行动 / 命中后）——
毒发、流血、回春、眩晕、蓄力释放、血契吸血全部是状态图上的原子组合，可在编辑器
分别编辑；新建同 mods / 同钩子的状态无需改引擎。持续参数统一命名 `turns`，
效果图中以 `"$参数名"` 引用施加参数（含个性化 / 共鸣结果）。

### 四、编辑器升级

- 条件节点双输出端口（pass / fail 红色分支连线）；调色板新增「结构（循环）」区；
- **loop 循环为自适应容器**：虚线框按循环体子树的真实渲染尺寸收缩 / 扩张，
  拖动容器头部整体移动子树；**一键包裹**（选中节点后点调色板「循环」或属性
  面板「包裹为循环」，子树自动移入容器并避开容器头部）与**一键解除**（保留
  循环体）；删除容器连带删除整个循环体；
- **战斗页变为三栏状态编辑器**：左 = 战斗常数（折叠）+ 状态列表；中 = 该状态的
  效果图画布（状态钩子调色板）；右 = 状态定义表单（策略字段 / params 规格 /
  mods 表 / lethal）或选中节点参数表单；
- 节点参数的 `$引用` 与战报模板 `event` 参数均有专用控件（文本 / 下拉）；
  节点拖动改为轻量直更（连线 / 容器实时跟随），端口拖拽轨迹残留兜底清理；
  全部技能图与状态图重排为按深度分列的整洁布局（分支上下分行、循环体
  下移避让容器头部）。

## 动机

- v2 的 23 个原语里仍有大量复合语义（蓄力 / 雷罚 / 血契 / 反甲各成一体的
  「迷你技能」），不可自由组合编辑；v3 把它们全部拆成攻击方式与基础变动的
  最小原子，图语言补全判断 / 分支 / 循环后，任何现有技能都能在节点画布上
  从零搭出来，状态也一样。

## 对确定性的影响

- **breaking：同名对战结果改变。** 确定性契约不变（同名同命 / 种子流水线 /
  个性化顺序：熟练度→value→前缀→后缀→共鸣槽；随机消耗顺序 = 技能派生顺序 ×
  触发节点数组顺序 × 边数组顺序（pass 组先于 fail 组）× loop 轮次，均有测试守护）。
  语义变化点：
  - 雷罚续链概率由 `chance×decay^(i-1)` 改为 `decay^(i-1)`（外层 chance 已消耗首道，
    后续道概率略升）；雷罚宣告行 thunder_cast 并入首道战报；
  - 记仇释放由「并入本次命中伤害」改为独立附加打击（不吃本次穿透 / 暴击）；
  - 记录随持有状态被驱散（净化可清记仇记录）；
  - 蓄力改为显式 skip_action 节点占行动；血契转化读取「本次行动吸血累计」；
  - 状态参数名统一（毒 damage→value、持续统一 turns、破甲上限 max_stacks）；
  - 眩晕 / 流血同在时按施加顺序结算（原为流血全体先于眩晕）。
- 平衡漂移（60 名字 400 场，供纯配置回调）：偏强 眩晕重锤 83.8% / 雷罚 75.7% /
  重击 70.7% / 血契 67.8%；偏弱 厚积薄发 17.6% / 撕裂 33.8% / 千锤百炼 34.4% /
  回春 36.2%；平局 0%；先手偏差 0.5%；平均 131.6 刻。引擎侧无问题
  （62/62 测试绿；300 场事件流确定；性能 1.18ms/场）。
