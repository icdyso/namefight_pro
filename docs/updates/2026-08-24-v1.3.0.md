# v1.3.0 更新（2026-08-24）

## 变更内容

1. **头顶血条当前段改白色**：角色名头顶简易血条的「当前生命」段由蓝色改为
   白色（蓝与蓝方阵营名配色易混淆）；红=本次掉血、绿=本次回血、灰=空不变。
2. **暴击加成按百分数显示（修复）**：用户反馈「洞悉」描述「暴击率 +6」应为
   6%。根因：`charge`（重击）与 `armor_pen`（洞悉）的 `crit` 字段以
   「百分点整数」存储（6 = 6%），而展示层与共鸣体系（`format_pct`、前端
   `fmtPct`、live 重算）均按「分数」口径（0.06 = 6%），整数口径只能显示成
   裸数字。修复：字段统一改为分数口径（配置 `crit: 25 -> 0.25`、
   `6 -> 0.06`），技能描述与战报显示「暴击率 +6.00% / +25.00%」；
   `RESONANCE_SPECS` 同步（`("charge","crit")` 与 `("armor_pen","crit")`
   均为 `("pct", 0.0, 1.0)`，即上限 100%）。**附带修复既有隐患**：
   `("armor_pen","crit")` 原 spec 为 `("num",0,200)`，共鸣后的暴击加成几乎
   总被错误截断到 5 个百分点，现按百分比口径正确截断。
3. **真战力系统（新功能）**：
   - 新模块 `namefight/power.py`：与 N 个固定编号敌人（名字 "1".."N"）各打
     一场极速对战，**胜场数即真战力**（平局不计胜）；
   - `run_battle` 新增 `record=False` 模式：不记录任何战报条目，随机数消耗
     与胜负和常规对战完全一致（供批量模拟）；
   - 新接口 `POST /api/power`（`{name, count?}`），返回真战力、总场次、
     胜率、耗时与现行面板战力（两套并行显示）；
   - 新独立页面 `/power.html`（`web/power.html` + `web/js/power.js`，
     文案走 `ui.json` 的 `power_*` 键），主页页眉新增「真战力」入口；
     **只在显式测量时运行，正常对战不触发**；
   - 敌人数配置于 `battle.json` 的 `power_check.enemies`。性能实测：单场
     极速对战约 0.45ms，100000 场约 45 秒判定过长，**默认 10000 场**
     （约 4~5 秒，含编号敌人派生缓存，配置热重载后自动失效重建）。

## 动机

- 蓝色血条与蓝方阵营名视觉混淆；
- 暴击加成单位口径不一致导致文案误导，且共鸣截断上限有错；
- 面板战力只是加权数值，用户需要以真实胜场衡量名字强度。

## 影响面

- 引擎：`battle.py`（record 参数、charge/armor_pen 暴击判定与
  `charge_release` 文案）、`fighter.py`（RESONANCE_SPECS、nat 模板参数）；
- 新增：`namefight/power.py`、`web/power.html`、`web/js/power.js`；
- 配置：`skills.json`（crit 值 25->0.25、6->0.06）、`battle.json`
  （power_check）、`ui.json`（power_* 文案）、`system.json`（版本 1.3.0）；
- 服务：`server.py` 新增 /api/power 路由；`config.py` 解析 power_enemies；
- 前端：`app.js`（页眉入口、血条注释）、`style.css`（血条白色 + power 页样式）。

## 对确定性的影响

- 暴击加成改分数口径：**数值上等价**（0.25 与 25 个百分点判定完全相同），
  但 armor_pen 共鸣截断修复后极端情况的实际暴击加成会不同于旧版，
  同名结果可能改变（修复性质，breaking 标注）；
- 真战力：纯新增测量通道，不改变任何对战结果；record=False 与常规模式的
  胜负一致（有既有极速模式契约保障）。

## 验证方式与结果

- `python -m unittest discover -s tests`：**59/59 通过**；
- `node --check` app.js / power.js：通过；
- 真战力实测：「饿发」胜 5067/10000（面板战力 25261），复测同为 5067
  （确定性一致），单次测量约 4.7s；
- 文案抽查：「洞悉」显示「暴击率 +6.00%」、「重击」显示「暴击率 +25.00%」。
