# v3.4.0 新技能「洗礼」+ 审判标记 + on_status_expire 状态钩子

日期：2026-09-02 ｜ 版本：3.4.0 ｜ 性质：**breaking（技能池新增第 26 个技能，
同名斗士的技能抽取结果改变）**

## 新技能：洗礼 baptism

- 攻击时 22% 概率：自身与敌方**各回复 600 点**体力，命中则给敌方刻下 1 层
  **审判标记**（judgment，layers 模式）：每层 900 点、独立倒数 12 刻，
  **到期各造成一次体力流失（可致死）**，可叠加、可被净化驱散（驱散即免除）；
- 熟练度作用于 value；value / turns 可个性化与共鸣（与毒同构）；
- 自然语言描述：`攻击时，有 22.00% 概率，回复自身 600 点生命，回复敌方 600 点
  生命，命中则刻下审判标记：每层独立倒数 12 刻，到期各造成 900 点伤害
  （可叠加、可驱散）。`

## 引擎：状态钩子 5 -> 6（on_status_expire）

「每层独立到期、到期即罚」在此前 5 个状态钩子（apply/tick/owner_action/
owner_action_consume/owner_attack_hit）下不可表达——on_status_lose 只在
**拥有者的技能图**上触发且整状态只发一次。新增：

- **on_status_expire**：layers 模式专用，每刻开始对每个到期层**各触发一次**
  效果图（审判：hp_mod loss $value can_kill），结算先于 on_status_lose；
- 触发点在 run_battle 每刻开始的失去检测之前（最后一层先炸、再发失去事件）；
  驱散 / 清除不触发（层数已清空且 live_prev 已更新，走 on_status_lose 路径）；
- hp_mod / gauge_mod / stat_mod 的允许钩子表加入 on_status_expire
  （marker / status_ctl / apply_status 本就走 ALL_HOOKS 自动获得）；
- `_status_death` 支持指定状态 id 取 death_event（审判最后一层炸完即不在场）。

## 顺带修正

- op_hp_mod / op_hp_mod_pct 模板补目标词：`回复自身 600 点生命` /
  `回复敌方 600 点生命`（此前敌方治疗也显示为无主语的"回复 600 点生命"）。
