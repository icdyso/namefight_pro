# 更新记录 - v0.1.0（初始版本：名字竞技场）

- 日期：2026-08-22
- 类型：feat（初始发布）
- 提交：`6c2a1c9`（AGENTS.md 首次提交）+ 本次提交（完整实现）

## 变更内容

1. **需求固化**：`AGENTS.md`——核心不变量（同名同命 / 功能-文案解耦）、技术约束、更新流程。
2. **后端**（纯 Python 标准库，零第三方依赖）：
   - `namefight/rng.py`：splitmix64 确定性 PRNG（含金向量测试，锁定算法防漂移）；
   - `namefight/config.py`：双层配置加载与启动校验（game=数值规则 / locales=文案）；
   - `namefight/fighter.py`：名字 → 归一化 → MD5 → 稀有度/元素/六维属性/技能(2–3个)/称号/战力；
   - `namefight/battle.py`：确定性回合制对战引擎——12 种技能效果（重击/斩杀/嗜血/淬毒/眩晕/连击/铁壁/荆棘反甲/疾风步/心眼/回春/背水一战）、六元素克制、四档稀有度、毒结算、眩晕、追击、反伤、超时判定；
   - `namefight/text.py`：模板渲染，战报以「模板 id + 参数（含 ref 引用）」结构化存储，渲染时套语言；
   - `namefight/server.py` + `server.py`：HTTP 服务（静态资源 + `/api/health`、`/api/text`、`/api/fighter`、`/api/battle`）。
3. **前端**（无构建、零依赖，自编写微型框架 `web/js/framework.js`）：
   - 双名字输入、斗士卡牌（称号/稀有度星级/元素/MD5 摘要/六维属性条/技能列表/战力）；
   - 战斗实录逐条回放：播放/暂停/跳过/0.5–4 倍速；
   - 结果横幅（胜者/平局 + 回合数与双方总伤害）；
   - 中英文一键切换，切换后自动重新拉取当前数据（验证结果不变）。
4. **配置化**：`config/game/*.json`（全部数值与规则）与 `config/locales/{zh,en}/*.json`（全部文案，每语言 7 个文件）彻底分离；技能描述只写风味文本，数值唯一来源是 game 配置。
5. **测试**：`tests/test_determinism.py`（同名同命、大小写归一、语言无关、对战可复现、输入顺序无关、镜像对战、跨进程一致）、`tests/test_config.py`（配置完整性、locale 全覆盖、UI 键对齐、PRNG 金向量、模板渲染安全）。

## 对确定性的影响

- 初始版本，无历史行为可比。
- 自本版起固定：派生 PRNG 消耗顺序（稀有度→元素→属性→技能数→技能→称号）、对战种子规则（排序后双方规范化名字以 `\x1f` 连接取 MD5）、先后手规则（速度降序、名字升序）。后续任何变更需按 AGENTS.md 3.4 标注 breaking。
