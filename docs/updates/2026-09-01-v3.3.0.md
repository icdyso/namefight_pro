## 变更内容

### 特例字段的彻底归并（用户方向：一切行为皆为图上原子组合）

v3.2 及之前，状态定义里有两个「逃逸口」特殊字段。v3.3.0 用两个新结算点
钩子 + 现有原子把它们原生化，状态定义不再有任何行为性特例字段：

- **reset_on_miss（攻击落空清零）→ 删除**。新增技能钩子 `on_attack_miss`
  （自己攻击落空时）；乘胜的清零改为技能图链：
  `on_attack_miss → status_ctl(momentum, stacks, -99)`（层数归零，容器保留）；
- **lethal（不屈致命拦截）→ 删除**。新增技能钩子 `on_lethal`（自己生命将
  降至 0 以下时——钩子内可救援，结束仍 ≤0 才死亡）；不屈改为技能图链：
  `on_lethal → chance("0.52 * pow(0.5, $self.mark:不屈)") → hp_mod(回复 28%
  最大生命) → marker(不屈 +1) → apply_status(will_used 展示)`——概率衰减
  由**表达式 pow(底数, 标记层数) + marker 计数**原生表达（表达式新增
  `pow` 函数）；will 状态降级为纯展示（无参数、无 lethal 块）。

### 连带修正

- 个性化流水线：表达式参数（字符串）不再参与熟练度 / 数值扰动 / 词缀 /
  共鸣的数值缩放（作者用表达式即精确控制）——mastery 文本对表达式 chance
  走倍率口径；
- marker 原子的 value（层数增量）取消可共鸣标记（无展示位且无共鸣语义）；
- 清理 dead code：statuses.clear_stacks、lethal 引用校验、状态显示的
  lethal 特例、编辑器状态表单的两控件（附原生实现指引文案）。
