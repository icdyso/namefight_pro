# v1.2.1 更新（2026-08-24）

## 变更内容

本版本包含两部分：**用户手动添加的 112 个称号词条**（前缀 62 / 主体 50，此前为
占位描述 "-" 与统一「攻击+100」占位加成），以及在其基础上的五项改动：

1. **速度与行动槽 ×100 量纲**（breaking）：
   - `attributes.json`：spd 10/[5,15] -> **1000/[500,1500]**，`power_weight`
     2 -> 0.02（战力口径不变）；
   - `battle.json`：`gauge_threshold` 100 -> **10000**（约每 10 刻一动的
     节奏不变）；
   - `skills.json`：速度/行动槽相关参数同步 ×100--斩断倒退 9 -> 900、
     疾影突袭前进 28/48 -> 2800/4800、大器晚成叠速 +1 -> +100；
   - `titles.json`：既有词条速度加成 ×100（苍穹/雷霆/游侠 +1 -> +100、
     退役 -1 -> -100）；
   - 动机：旧量纲下速度投掷只有 11 个整数取值、行动槽推进量取整占比过大，
     ×100 后取整粒度大幅变细、对数值的影响显著减小。
2. **战报角色名带称号 + 头顶简易血条**：
   - 后端 `_Combatant.name` 改为「【称号】名字」显示名（新增 `plain_name`
     保留原始名字供胜负方 API 字段使用），全部战报行与胜利宣告均显示全名；
   - `attack_hit` / `thunder_hit` 模板删除「（X 剩余 N）」剩余生命文本
     （`hp` 参数一并移除）；
   - 前端在每个角色名（rich 段 name-a/name-b）头顶渲染**无数字简易血条**：
     蓝=当前生命、红=本次掉血、绿=本次回血、灰=空；数据 = 本条快照与上一条
     快照的生命差值（逐条 / 跳过 / 单回合递进模式一致）；结算横幅同样显示
     「【称号】名字」。
3. **称号结构固定为「前缀+主体」**：`titles.json` 的 structures 仅保留
   `prefix_core`（连接符空串直拼，如「暗夜剑圣」「可能是王者」）；引擎与
   JSON 结构未动，后缀池保留备用。
4. **为用户添加的 112 个词条补全描述与加成**：每条配 4~6 字风格化描述与
   语义对应的属性加成（**最多三种属性、大胆使用负值**，如「胆小的」闪避+2/
   速度+100/攻击-100、「禁忌」攻击+200/生命-300/暴击+2、「大块头」
   生命+800/攻击+100/速度-150）。
5. **新增候选词条库 `docs/title_candidates.md`**：按上述编写思路给出
   **500 个前缀候选 + 500 个主体候选**（含描述与加成，格式与 titles.json
   完全一致、可直接粘贴；池内不重复且与现有词条不重复，已脚本校验），
   供人工筛选后手动并入。
6. **AGENTS.md 精简改版**：按用户要求省去一切不必要的流程--测试仅在
   改动引擎/派生/PRNG 等底层时运行，明确「以完成任务为核心、不过度设计、
   不写多余验证脚本」，全文由 265 行压缩至约 130 行并同步现行事实
   （单层配置、×100 速度量纲、称号结构、战报血条协议等）。

## 动机

- 取整对小量纲速度/行动槽影响过大，统一 ×100 消除；
- 战报阅读体验：称号彰显身份；数字血量信息改由可视化血条承载；
- 用户扩充称号池需要成体系的描述/加成与后续候选来源；
- 降低 Agent 会话的 token 消耗与流程开销。

## 影响面

- 引擎：`namefight/battle.py`（combatant 显示名、hp 参数移除、side_of_name
  口径）；其余引擎逻辑未动；
- 前端：`web/js/app.js`（nameWidget 血条、结算横幅全名）、`web/css/style.css`；
- 配置：attributes / battle / skills / titles 四个 JSON；文档：GAME_SPEC、
  README、AGENTS、本更新文档、新增 title_candidates.md；
- 测试：`test_real_value_display`（spd 量纲）、`test_faster_fighter_acts_first`
  （战报名带称号）两处断言同步更新。

## 对确定性的影响（breaking）

**会改变同名结果**（属正常，见 AGENTS.md 2.1.7）：

- 速度投掷区间与行动槽阈值变化 -> 行动节奏与全部对战结果改变；
- 称号池扩充 + 结构固定 -> 称号派生改变（连带称号加成下的属性）。

版本号沿用用户设定的 **1.2.1**（本次改动与其称号扩充合并为一个版本）。

## 验证方式与结果

- `node --check web/js/app.js`：通过；

  形式，「命中」行无剩余生命括号，快照 spd ~1000 / 阈值 10000；
- `docs/title_candidates.md` 脚本校验：前缀 500 / 主体 500，池内无重复、
  与现有词条无重复、bonus 均 ≤3 种已知属性。
