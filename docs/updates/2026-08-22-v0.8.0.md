# v0.8.0 — 共鸣公式化简 + 对战实时技能数据 + 简易显示 + 前端整数显示 + 15 个新技能与平衡调整

日期：2026-08-22 · 版本：v0.8.0（`config/game/system.json`）

## 变更内容

### 1. 共鸣描述公式化简 + 「当前」措辞（需求 1）

- 公式从「基数 + 基数 × 变量式 × 单位系数」化简为**最简线性形式**：
  `（基数 + （变量式）× 合并系数）`，合并系数 = 基数 × 倍率 ÷ 变量基础值；
  实例：「攻击时有 15.14% 概率使本次伤害提升至 231.52%（200.00% + 敌方当前生命× 0.82%）」；
- 所有变量描述改为**当前值措辞**（己方当前生命 / 敌方当前防御…），
  公式与尾句同步（「己方当前生命高于敌方当前生命越多，效果值越高。」）；
- locale `stats.json` 新增 `link_expr_difference`（差值变量式）与 `current_word`。

### 2. 对战实时技能数据 + 简易显示模式（需求 1）

- 后端为每个共鸣技能提供 `live_text` / `live_text_simple`（主句数值位为
  `\u0001` 标记）与 `link_calc = {base, coeff, mode, source, variable, against,
  clamp, fmt}`；前端按快照逐刻计算 `最终值 = base + 变量式 × coeff`（含上下限
  截断），替换标记实时刷新卡牌数值（变化时闪烁提示）；该公式与引擎
  `resonance_coeff + apply_resonance` 逐点一致（新增测试保障）；
- 战报快照补全 `crit` / `dodge`（并让 `def` 反映破甲后的有效防御），
  前端实时公式所需属性全部可从快照直接取用；
- 前端新增**简易显示模式**开关（页眉，localStorage 记忆）：隐藏技能描述括号内
  公式，尾句保留；切换后实时数值按最近快照恢复，不中断回放。

### 3. 展示精度调整（需求 1）

- **前端除百分数外的所有数值保留整数，百分数保留 2 位小数；后端不变（全浮点）**；
- 后端展示层同步：`format_num` 改为整数（"8" / "95"），`format_pct` 不变；
  战报 / HUD / 汇总 / buff 参数 / 技能描述统一该规则；
  快照数据层仍保留 2 位小数（仅展示时取整）；
- AGENTS.md 2.1.5 与 GAME_SPEC 2.2 的数值精度契约同步修订。

### 4. 15 个新技能 + 全池平衡调整（需求 2）

新增（均为独立机制设计）：乘胜追击（连击叠层·落空清零）、燃血轰击（耗血换爆发）、
破甲连打（叠层削防·随行动递减）、撕裂（按攻击动态定伤的流血）、趁虚而入
（敌方负面状态/即将行动时增伤）、疾影突袭（命中推进行动槽）、孤注一掷（高方差豪赌）、
坚守壁垒（高血量减伤·后期衰减）、以牙还牙（被暴击叠暴击）、不倒意志
（一场一次挡致命伤）、净化（解除毒/血并回复）、大器晚成（第 40 刻提速）、
洞悉（百分比破防）、血契（开战耗血换攻击）、怨念深重（挨打叠伤害层）。

- 引擎新增 15 种效果类型与对应结算（含血契/提速的一次性钩子、
  命中反应钩子 `_after_hit`、致命伤拦截 `_hurt`）；
- 新增 11 种 buff 徽章与 15 条战报模板（双语言）；
- **平衡方法**：新增 `tools/balance_check.py`（固定种子蒙特卡洛，6000 场），
  统计每个技能持有者胜率；经过 8 轮调参：
  - 燃血轰击初版胜率 **82.9%** → 调整为 ×1.3 / 耗血 11% → **51%**；
  - 趁虚而入初版 **36.9%**（多数对局无事可做）→ 加入破甲与「即将行动」
    触发条件 → **54%**；
  - 成长/爆发类（乘胜、怨念、背水、重击、荆棘、铁壁等）普遍下调——
    实测后期伤害的胜率敏感度约为数值预期的 2 倍（归零实验证实非实现缺陷）；
  - 终版 27 技能胜率区间 **43.3%–56.6%**，其中 25 个落在 45%–56%；
    净化（43.3%）为刻意保留的克制型技能（权重已降至 5）；
  - 先后手位置偏差 1%–3%（跨 3 个种子），属抽样噪声范围。
