# 更新记录 - v1.0.0（量纲微调 + 熟练度高斯 + 播放模式 + 创意工坊）

- 日期：2026-08-23
- 类型：feat
- 提交：`c5399b5`

## 变更内容

1. **数值小调整**（breaking，同名结果改变）：
   - **速度与行动条回退上一版本量纲**：速度 base 10、投掷 [6,14]，
     `gauge_threshold` 100（约每 10 刻一动）；
   - **防御数值减半**：base 750、投掷 [500,1000]；称号中防御/速度加成同步
     换算（防 ±50/±100、速 ±1）；
   - 量纲相关技能参数同步换算：破甲 460→340、斩断倒退 900→9、
     疾影前进 3300/5600→33/56、大器晚成 +97→+1；
   - 平衡重调（6000 场蒙特卡洛）：斩杀 33%/×2.45/门槛 33%、壁垒 −25%、
     燃血 ×2.15、血契吸血 68%、背水 +21%/+20%、大器晚成 27%；
     全部技能持有者胜率 45.9%–54.6%。
2. **熟练度服从高斯分布**：熟练度改为 `DetRng.next_gaussian_range(0, 100)`
   高斯投掷（集中于 50）；消耗随机数的方式与次数不变（同名结果不变）。
3. **普通攻击描述文本**：每次攻击行动（含蓄力释放/雷罚）前输出
   `attack_start` 战报行「🗡️ XXX 发起攻击！」（斩断反击不经过该宣告）。
4. **战报播放模式**：
   - 普通模式在每条停顿（`playback.message_delay_ms`）之外，
     每 `playback.action_pause_every`（默认 5）次角色行动（以 attack_start 计）
     插入一次较长停顿 `playback.action_pause_ms`（默认 1600ms），均可配置；
   - 新增**单回合递进模式**：不自动播放，「递进一步」每次推进一次角色行动的战报；
   - 简易显示模式下对战中同样显示实时变动的技能数据（live 文本随快照重算）。
5. **创意工坊**（`/workshop.html`，独立管理页）：
   - 可视化编辑全部六个配置 JSON：属性表、技能卡（效果参数/熟练度/词缀/共鸣池/
     stats 模板）、称号结构与字段池、战斗常数/战报模板/buff、系统、界面文案；
     支持增删条目、行排序与 JSON 源码模式；编辑仅影响草稿，页签以 ● 标记脏文件；
   - 「试运行」：以草稿配置推导并打一场（`POST /api/config/preview`，不落盘），
     展示胜负/双方概要/完整战报；非法草稿显示后端校验错误；
   - 「保存并生效」：`POST /api/config/save` 先经 `load_game_config_from_data`
     完整校验，再原子写盘并热重载服务配置（确认框防误触），无需重启进程；
   - 该页为管理向独立页面，界面文字直接书写于 `web/js/workshop.js`
     （AGENTS.md 已注明例外），未来可按需挂载权限。
6. 后端 `config.py` 抽出 `build_game_config` / `load_game_config_from_data` /
   `save_game_config`；`server.py` 新增 `/api/config`、`/api/config/preview`、
   `/api/config/save` 与 `AppState.reload()`。

## 动机

- 用户反馈：速度/行动条的大数值不直观，回退旧版小量纲更易读；防御减半缓解
  高防御下的磨局；熟练度应服从高斯分布；普通攻击缺少可见文本；
  战报需要更从容的节奏（行动间停顿）与可手动推进的递进模式；
  配置修改需要低门槛的可视化编辑与即时测试入口。

## 影响面

- 配置：`attributes.json`（def/spd 量纲）、`titles.json`（def/spd 加成）、
  `skills.json`（量纲相关参数与平衡）、`battle.json`（阈值 100、playback 两新键、
  `attack_start` 模板）、`system.json`（版本 1.0.0）、`ui.json`（播放控制文案）；
- 后端：`config.py`、`server.py`、`fighter.py`（熟练度高斯）、`battle.py`
  （attack_start 事件）；
- 前端：`web/js/app.js`（递进模式/行动停顿/工坊入口）、
  新增 `web/workshop.html`、`web/js/workshop.js`、`web/css/workshop.css`；
- 文档：`AGENTS.md`、`docs/GAME_SPEC.md`、`README.md` 同步。

## 对确定性的影响

- **breaking**：防御/速度量纲与技能参数变更，同名斗士的属性（def/spd 投掷区间）
  与同名对战结果改变；属用户要求的数值规则变更，按流程显著标注。
- 熟练度高斯投掷保持个性化 PRNG 消耗顺序与次数不变（仅抽样函数形态变化），
  同名熟练度数值会改变（属派生规则变更）。
- 确定性契约本身不变：一切仍为（名字 + 配置快照）的纯函数；
  `attack_start`、播放模式、工坊均为展示/工具层，不影响对战种子与事件序列
  （播放停顿为纯前端行为；试运行使用独立的草稿配置，不改变生效配置的结果）。
