# 更新记录 - v3.10.0（Toy 静态版：JS 引擎移植 + B站 Toy 平台发布支持）

- 日期：2026-09-17
- 类型：feat
- 提交：`<commit hash>`

## 变更内容

- **JS 静态引擎**（`web/js/engine/`，11 个文件）：Python 引擎的逐模块移植——
  md5 / pyfmt（银行家舍入、`%.2f` 半偶精确十进制、码点序排序等 CPython 口径兼容层）/
  rng（splitmix64，BigInt）/ text / expr / effects（注册表 + 图编译）/ statuses /
  config / fighter / battle / api。产出与后端各端点（/api/text、/api/fighter、
  /api/battle、/api/power）**完全相同形状**的 JSON。
- **静态包构建** `tools/build_toy.py`：对战页 + 真战力页 + 引擎 + 六份配置
  （构建时嵌入为 `nf_data.js` 快照）打成一个纯静态目录（约 280KB / zip 81KB），
  可直接发布到 B站 Toy 平台（`/toy/<slug>/` 子路径，纯静态托管）。
  编辑器页需后端保存，不随包。
- **前端双模式**：三页资源引用全部改为相对路径（服务器模式与子路径静态托管
  均适用）；`framework.js` 支持注入本地引擎 API（`NF.localApi`），静态包页面
  优先走本地引擎，服务器模式行为完全不变；静态模式下隐藏「编辑器」入口。
- **真战力页静态模式**：本地分块模拟（每块 250 场、让出主线程、显示进度），
  默认 10000 场在浏览器约 9 秒（实测比 Python 服务器侧约快一倍）。
- 新增差分验证工具 `tools/port_check.mjs`（Node 零依赖）：起 Python 服务器与
  JS 引擎全量对拍（fighter / 全量战报含 rich 与快照 / power / 错误路径，
  深比较到 JSON 路径），**引擎类改动后建议回归**，保证两版同名结果永远一致。

## 动机

- Toy 平台（bilibili/toy）为纯静态托管，无任何后端；本项目对局逻辑原本全在
  Python 服务器。引擎全部为纯计算零 IO，具备完整移植条件——同名同命契约在
  JS 版同样成立（派生 = f(归一化名字, 配置快照) 的纯函数）。

## 对确定性的影响

- **无 breaking**：Python 引擎、派生、PRNG、配置均未改动，服务器模式同名结果
  与 v3.9.1 完全一致（版本号本身除外）。
- JS 引擎为独立移植，同名结果经差分验证与 Python 逐字节一致（见验证）；
  静态包配置为构建时快照（配置即输入的正常语义）。

## 验证

- `node tools/port_check.mjs`：**95 组检查 0 不一致**（31 个名字派生、56 组
  全量对战（含中文/emoji/星面字符、镜像、换序、大小写）、power 小样本、
  空/超长名字错误路径）。
- 真战力全量对拍：张三 10000 场 Python 5687 = JS 5687（Python 18.8s / JS 8.7s）。
- 静态包装配：注入页按脚本顺序加载后 `NF.localApi` 可用、对战产出完整战报；
  `toy_doctor.py dist/toy --slug namefight-arena --json` → `{"ok": true, "findings": []}`。
- 服务器模式冒烟：三页 + 静态资源 + API 全部 200，对战正常（相对路径改动无影响）。
- Python 引擎未改动，按规约未跑 unittest 确定性套件（差分测试已覆盖同名一致性）。
