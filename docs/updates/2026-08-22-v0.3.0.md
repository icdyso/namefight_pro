# 更新记录 - v0.3.0（平滑行动条 / 悬停详情 / 称号加成 / 变量共鸣）

- 日期：2026-08-22
- 类型：feat（**breaking：会改变同名对战结果**）
- 提交：`<见 git log>`

## 变更内容

1. **行动条平滑播放（需求 1）**：HUD 行动槽不再随战报条目突变--
   上升段按当前回放节奏（基础间隔 ÷ 倍速）以 CSS 线性过渡平滑推进，
   行动消耗时 150ms 快速回落，跳过/初始化时瞬时应用。
2. **技能与状态详情 + 防闪烁（需求 2）**：
   - 技能与 buff 徽章均支持**悬停详情**（自定义 tooltip）：技能显示
     机制描述（detail）+ 风味文本 + 个性化参数；buff 显示当前数值
     （detail，如「每次行动损失 9 点生命（剩 3 次）」）+ 机制说明（desc）；
   - buff 徽章改为**差量刷新**：集合签名（id+参数）不变时不重建 DOM，
     消除原先每条战报重播入场动画造成的闪烁；
   - locale 新增字段：`skills.json` 每技能 `detail`、`buffs.json` 每条 `desc`。
3. **称号小额加成（需求 3）**：称号各字段自带小额属性加成
   （`game/titles.json` 各字段 `bonus`，可为负——「候补」攻击-1、「退役」速度-1
   带点幽默），在稀有度倍率之后叠加；卡牌新增「称号加成：生命 +3 · 攻击 -1 ·
   暴击 +1%」展示行，战力同步反映。结构越完整通常加成越多。
4. **技能变量共鸣（需求 4）**：可共鸣类型（重击/斩杀/连击/淬毒/眩晕）的技能
   有 60% 概率与一项自身属性建立共鸣；**共鸣变量与倍率均由
   `md5(名字:技能id)` 独立种子决定**（变量池与倍率区间在 `variable_link`
   配置）。触发时附加 `属性值 × 倍率` 的伤害（淬毒类加在毒伤上）。
   共鸣以**技能名后缀标记**体现：「淬毒之刃·坚」（防御）、「重击·命」（生命）、
   「淬毒之刃·锋」（攻击）；标记文案在 locale `stats.json` 的 `link_*` 键。
   战报新增 `effect_link` 模板：「⚡ 吕布 引动自身攻击，附加 7 点伤害！」
5. 版本号升至 0.3.0；AGENTS.md 已同步派生顺序（含共鸣抽取顺序）与设计备忘。

## 对确定性的影响

- **breaking**：称号加成改变属性与战力，共鸣改变伤害，同名对战结果与 v0.2.0 不同。
- 「同名同命」契约不变：所有新机制（称号加成查表、共鸣抽取）均为
  (名字, 配置) 的纯函数；测试 37/37 通过，跨进程一致、逐字节复现验证通过。
- 共鸣与个性化同用独立种子 `md5(名字:技能id)`，消耗顺序固定为
  chance -> value -> damage -> 是否共鸣 -> 变量 -> 倍率。
