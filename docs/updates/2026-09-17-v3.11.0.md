# 更新记录 - v3.11.0（熟练度大波动：全池触发率倍率统一 [0.25, 2.5]）

- 日期：2026-09-17
- 类型：feat（数值平衡，**breaking**）
- 提交：`fecd3f9`

## 变更内容

- **熟练度倍率区间全池统一 [0.25, 2.5]**（原多数为 [0.7, 1.5]，少数
  [0.5, 1.65]）：27 个技能全部生效，触发率随熟练度呈 **10 倍落差**波动——
  低熟练度实例可被钳到 2% 下限（CHANCE_CLAMP [0.02, 0.95] 收口），高熟练度
  普遍触顶 95%；效果值类参数（不屈回复比例 / 背水加成 / 洗礼治疗与审判）
  同步获得同等波动。
- 倍率均值 1.375（熟练度三角形分布集中于 50），整体触发率较旧区间上移
  约 18%~25%，同时方差大幅拉大——同名不同命的个体差异显著放大。
- `docs/GAME_SPEC.md` 同步：头部版本 v3.11.0、技能表熟练度区间列全部更新、
  触发率段落补充说明。

## 动机

- 用户需求：触发率需要随熟练度都有大幅度的波动。旧区间下高基率技能
  （雷罚/疾影等 lo=0.85）几乎不随熟练度变化，个体差异被压缩。

## 对确定性的影响

- **breaking**：纯配置数值变更，改所有名字的技能实例数值（触发率/效果值）
  与全部对战结果；引擎、派生顺序、PRNG 消耗完全不变，同名结果依旧确定
  （只是数值口径整体切换）。

## 验证

- `python -m unittest discover -s tests`：**70 个测试全部通过**。
  其中「洗礼审判逐层到期」测试为隔离数值波动做了三处定制配置调整
  （钉熟练度 [1,1] / 去互奶 / atk_factor 压保底使审判决定生死、value 800→2000），
  机制断言（逐层到期 / 施加刻+持续 / 致死 / 双跑一致）全部保持。
- 波动实证（60 个名字派生抽样）：重击 19.6%–55.5%（基率 28%）、
  斩杀 28.4%–95%（基率 66%）、千锤百炼 83.6%–95%（基率 95%）；
  熟练度倍率实测样本 0.43–2.5，中位约 1.44。
