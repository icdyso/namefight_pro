# 更新记录 - v0.9.1（属性正态投掷恢复 + 白板100纯显示层换算 + 元素系统删除 + 触发率修复）

- 日期：2026-08-23
- 类型：fix / feat（含 breaking 数值变更）
- 提交：`<commit hash>`

## 变更内容

1. **属性恢复正态分布随机投掷**（用户报告 v0.9.0 误删属性随机）：
   - 六维属性在各自 `[min, max]` 内高斯投掷（均值 = 区间中点，σ = 区间宽 ÷ 4，
     截断到区间），消耗顺序 = 配置顺序（每维一次高斯，主 PRNG 首位消耗）；
   - 投掷值 + 称号加成 = 面板属性（下限 1），全程浮点；
   - v0.4 时代为均匀整数投掷，本次按用户要求改为**正态**（复用
     `DetRng.next_gaussian`）。
2. **引擎数值回退原始量纲，白板 100 改为纯显示层换算**（用户澄清
   「以 100 为参考、实际计算时再除回去、只影响显示」）：
   - `attributes.json` 回退 v0.8 量纲：hp 100（80–120）/ atk 13（10–16）/
     def 5（2–8）/ spd 10（6–14）/ crit 12 / dodge 10，战力权重 1/4/3/2/2/2；
   - `battle.json`：atk_factor 与 defense_factor 均为 1.0、gauge_threshold 100；
   - `titles.json` 称号加成回退（攻/防/速 ±1 或 ±2）；
   - 技能绝对值按量纲换算：斩断 delay 150→15、疾影突袭 260/450→33/56、
     大器晚成 +3.0→+0.34、破甲 34→1.7、血契转化 0.6→7.8%；
   - **显示层**：`attributes.json` 新增 `display_ref`（= 满投掷 max），
     显示值 = 引擎值 ÷ display_ref × 100（如攻击 13 → 81.25）；卡牌属性 /
     称号加成行 / HUD / 快照属性 / 战报全部数值（伤害/回复/破甲/叠速等按各自
     量纲）/ 共鸣公式基数与合并系数 / link_calc 的 base/coeff/clamp
     均为白板 100 显示单位；引擎与配置计算不受影响；
   - 暴击/闪避本身即百分数，不参与换算（卡牌显示 2 位小数）。
3. **元素系统整体删除**（用户要求删除青木/惊雷等元素）：删除
   `config/game/elements.json` 与双语言 `elements.json` locale、派生抽取、
   `Fighter.element_id`、API `element` 字段、卡牌元素徽章、
   battle_start 战报元素参数及相关配置加载与测试。
4. **触发率修复**（用户报告「触发率超过 100%、各技能应按强度互不相同」）：
   - 熟练度行由倍率写法「触发率 ×149.60%」改为**最终触发率**
     「熟练度 86：触发率 25.43%」（壁垒类显示免疫触发率、条件型显示效果倍率
     ×1.21），任何展示口径的触发率永不超过 100%（个性化后截断 [2%, 95%]）；
   - 25 个技能基础触发率按强度**全部互不相同**（强效低频：斩断 10% / 重击 16% /
     眩晕 17% … 弱效高频：铁壁 65% / 雷罚 78% / 乘胜 80% / 大器晚成 84%），
     新增测试保证唯一性。
5. **速度 emoji 改为 👟**（原 💨），双语言同步。
6. **共鸣差值/并值模式改为与同名属性运算**（`diff_against` 缺省为变量自身，
   攻↔攻、速↔速等）：显示一致性需要（不同属性显示系数不同，跨属性差值无法
   在白板 100 显示单位下线性展开），且与「【己方-对方】⚔️」单 emoji 记法吻合。
7. **平衡性重新调参**（属性随机恢复后防御 [2,8] 浮动放大防穿/续航价值，
   首测 43.3%–59.0%）：四轮蒙特卡洛调整（斩断/回春/嗜血/洞悉/不屈/背水下调，
   怨念/疾影/大器晚成上调等），终测 25 技能持有者胜率 **45.6%–54.8%**
   （10000 场，`tools/balance_check.py`）。

## 动机

- 用户澄清 v0.9.0 的「白板 100」被误解为引擎基础值全部改为 100（所有人属性
  变为 100、且属性随机被误删），实际意图是**以 100 为满投掷参照的纯显示换算**，
  引擎保持原始量纲（例：攻击基础 d ∈ 0–15，若为 10，显示为 100/15×10）；
- 用户明确属性值应**服从正态分布随机投掷**；
- 用户要求删除元素系统（🌿青木/⚡惊雷等纯装饰）；
- 用户报告触发率出现超过 100% 的展示（熟练度倍率写法），且要求各技能触发率
  按强度互不相同；
- 速度图标改为 👟。

## 对确定性的影响

**有（breaking，v0.9.1）**：

- 属性恢复随机投掷 + 删除元素抽取改变主 PRNG 消耗序列--所有名字的派生结果
  （属性/技能/称号）与对战结果均与 v0.9.0 不同；
- 量纲回退 + 技能绝对值换算在数学上与 v0.9.0 等效，但称号加成回退取整
  （如战神 +15÷8≈1.875 → +2）与平衡调参（多个技能数值/触发率变更）为刻意
  数值调整；
- 差值/并值共鸣改为同名属性运算，同名技能实例的共鸣表现不同；
- 以上均已在本文档与 GAME_SPEC.md 中标注。
