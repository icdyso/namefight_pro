# v3.9.1 数值合理性复核 + 熟练度影响 ≥50% + 显示修复

日期：2026-09-02 ｜ 版本：3.9.1 ｜ 性质：**breaking（阈值去共鸣、熟练度区间
加宽、壁垒数值修，同名结果改变）**

## 1. 数值合理性全池复核（用户实例：壁垒「生命比例 ≥ 234.53%」）

审计发现两类荒谬值：

- **比较阈值被翻倍顶满**：壁垒 HP 门槛 0.7 ×2 顶到 clamp 1.0（=100%），
  再叠加共鸣显示 234%——回 0.7（描述语义 HP≥70%）；
- **阈值类参数本不该共鸣**：比较阈值（compare value）、层数比较值
  （stacks_cmp value）、标记层数门槛（has_marker count）移出共鸣候选——
  条件边界随属性漂移到 >100% 即成死条件。v1 的「触发门槛共鸣」废止；
- 壁垒减伤回调 0.5 → 0.35（×2 口径 0.16×2≈0.32 的贴值），胜率
  39.8% → 46.7% 回带；其余参数逐一审计，无可疑值。

修复后壁垒样例：「受到伤害时，自身生命比例 ≥ 81.39%，使所受伤害降低
35.00%，有 8.91%（6.54 + 👟*0.26%） 概率，完全免疫本次伤害」。

## 2. 熟练度影响提高到 50% 以上

全部技能熟练度区间高值统一 ≥ **1.5**（相对基线至少 +50%；16 个技能
自 1.15–1.45 上调，低值不动）——高熟练度斗士的技能数值至少比基线强
一半。

## 3. 显示修复：双百分号

「9.58%（7.32 + 🛡️*0.37%）%」的公式括号外补 % 是 v1 遗留显示约定，
数值位本身已含 %——废止外补，全字段去双百分号。

## 验证

- 70/70 测试通过；balance 复测：带宽 43.1%（破甲）–66.8%（背水），
  平均刻数 93.5（节奏保持）；
- GAME_SPEC 技能表按新数值引擎直出重建。
