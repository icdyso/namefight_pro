# 更新记录 - v0.4.0（共鸣机制重做 / 逐刻回放 / 技能词缀 / 完整规则手册）

- 日期：2026-08-22
- 类型：feat（**breaking：会改变同名对战结果**）
- 提交：`<见 git log>`

## 变更内容

1. **共鸣机制重做（需求 1）**：
   - 共鸣概率 0.6 → **0.95**，倍率区间整体大幅上调（如攻击共鸣 0.2–0.5 → 0.35–0.8）；
   - **来源**（己方 3 : 敌方 2）与**模式**（比例 3 : 差值 2）均由 MD5 决定并可配置；
   - 计算公式（写入 GAME_SPEC 并在卡牌展示）：
     `比例：bonus = round(源方[变量].当前值 × rate)`；
     `差值：bonus = round((己方[变量] − 敌方[参照]).当前值 × rate)`，负差不提供加成；
     差值参照为有意义配对（攻↔防、速↔速、命↔命、暴击↔闪避）；
   - **动态计算**：触发时刻取当前值——生命共鸣随掉血衰减、攻击共鸣含背水一战
     加成、敌方生命共鸣随敌方濒危而减弱；
   - 战报注明来源与模式：「⚡ 吕布 以敌方防御共鸣（比例），附加 2 点伤害！」。
2. **逐刻回放（需求 2）**：前端回放从"逐条战报"改为 **tick 时钟驱动**——
   每 `85ms ÷ 倍速` 推进一游戏刻，行动槽每刻 +速度%（客户端模拟 + 快照校正），
   战报条目在其所属刻到达时揭示。速度差异带来的**真实攻击间隔**得以直观呈现
   （GUI 采样验证：行动槽连续变化、条目按刻揭示）。跳过 = 瞬时。
3. **技能名称词缀（需求 3）**：前缀 50% / 后缀 40% 概率获得，附带微小参数修正
   （仅作用于技能已有参数）：疾风（触发率+3%）、猛烈（效果值+8%）、蚀骨（毒伤+1）、
   缠绵（持续+1）、浩大（双增益）；破军/蹈隙/入骨/不息/汹涌（权衡型：+12% 效果、
   -3% 触发）。名称组装 `前缀·技能·后缀·共鸣标记`（如「疾风·淬毒之刃·坚」）；
   tooltip 显示词缀明细（「猛烈：效果值 +8%」）。
4. **完整规则手册（需求 4）**：新增 `docs/GAME_SPEC.md`——总览/派生/战斗 mermaid
   流程图、全部细则与数值（属性/稀有度/技能/共鸣公式/称号加成/战斗常数表）、
   战报与快照结构、API 说明、**7 个 game JSON 与 10 个 locale JSON 逐文件的
   意义与调整指南（含示例）**、前端行为说明；版本号随手册头部维护。
   **AGENTS.md 新增第 3.6 条**：规则/数值/配置结构的更新必须同步更新该手册。
5. 配套：新增第 10 个 locale 文件 `modifiers.json`（词缀名称，双语言）；
   `stats.json` 新增来源/模式词、词缀修正模板、新共鸣模板（含开战参考值）；
   版本 0.4.0。

## 对确定性的影响

- **breaking**：共鸣概率/倍率/双来源/双模式与词缀修正均改变技能实际数值，
  同名对战结果与 v0.3.0 不同；称号与属性体系不变。
- 「同名同命」契约不变：全部新随机量来自 `md5(名字:技能id)` 独立种子的固定
  消耗顺序（chance → value → damage → 前缀 → 后缀 → 共鸣[是否→来源→模式→变量→倍率]）。
