# v3.5.1 编辑器配置界面中文化

日期：2026-09-02 ｜ 版本：3.5.1 ｜ 性质：修复（纯前端文案，不改同名结果）

## 变更

编辑器多处控件此前显示原始英文 id，全部改为数据驱动的中文标签：

- **节点参数枚举下拉**（此前 `options.map(o => [o, o])` 裸英文）：target /
  type / basis / scope / mode / stat / action / op 等全部经 `enumWord` 映射——
  属性枚举取属性配置名，其余查 stats 词表（enum_* 新增 + 复用既有
  ctl_* / cmp_* / cmp_target_* / lbl_marker_*）；
- **画布节点参数摘要**：枚举值与状态引用显示中文
  （`target = 自身 · type = 流失（扣血） · status = 审判标记`）；
- **状态钩子中文标签**（战斗页调色板与画布触发节点此前是
  `on_status_apply` 等裸 id）：施加时 / 状态结算 / 逐层到期 / 拥有者行动 /
  替换行动 / 拥有者命中，附中文悬浮说明；
- **战报模板下拉**：附中文模板预览（`baptism_heal（✨ {a} 受到洗礼…）`）；
- **mods 被动修饰种类下拉**：mk_* 短标签（增伤（乘区）/ 受伤减免 / 护盾池…）；
- **共鸣绑定模式下拉**：统一走词表，去掉「（own）」英文后缀。

新增 stats 词汇：6 组状态钩子 lbl_/dsc_、enum_* 值词、mk_* 修饰短标签。
